# Developer Assignment - Gaelta

Vypracované úlohy zo zadania pre vývojára. Každá úloha je uložená samostatne a dá sa otvoriť bez celej aplikácie.

## Obsah

| Úloha | Výstup |
| --- | --- |
| `task-1-shoptet-card/` | Úprava produktovej karty v HTML, CSS a JavaScript |
| `task-2-webhook-sheets/` | Návrh webhooku a ukážka prenosu dát do Google Sheets |
| `task-3-debug-js/` | Náprava JavaScriptu a porovnanie pred/po |
| `task-4-answers.md` | Odpovede na technické otázky |
| `task-5-platform-notes.md` | Poznámky k zľavám a platformám |

## Poznámky

- Ukážky predpokladajú Shoptet a vývojové prostredie bez ďalších build nástrojov.
- Konkrétne miesta vloženia sú popísané priamo pri jednotlivých úlohách.
