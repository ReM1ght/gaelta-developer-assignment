# Zadanie 1 - Shoptet sablona (produktova karta)

Obsah priecinka:

- `snippet.html` - ukazka HTML struktury produktovej karty
- `styles.css` - styling vratane hover efektu pre tlacidlo
- `script.js` - logika pre badge "Novinka" a text o doprave

## Kde to umiestnit v Shoptete (Admin)

1. `snippet.html` (cast struktury) vlozit do sablony produktoveho listingu:
   - Vzhlad a obsah -> Editor -> sablona vypisu produktov (kategoria)
2. `styles.css` vlozit do:
   - Vzhlad a obsah -> Editor -> CSS
3. `script.js` vlozit do:
   - Vzhlad a obsah -> Editor -> JavaScript

Poznamka: Nazvy sekcii v administracii sa mozu mierne lisit podla konkretnej sablony alebo doplnkov.
